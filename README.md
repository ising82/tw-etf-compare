# 📈 ETF 績效比較（台股・美股）

台股全部上市／上櫃 ETF 與約 250 檔代表性美股 ETF 的績效比較網站，每個交易日自動更新，跑在 GitHub Actions + GitHub Pages 上，免伺服器、Python 只用標準函式庫。頁首按鈕切換台股／美股。

- **主題總覽**：各主題（半導體、高股息、美國公債、國防航太…）在所選期間的平均報酬排行、期間最佳 ETF、近期各期間與**歷年報酬熱力表**；頁首摘要卡直接列出目前最強／最弱主題與大盤對照。點主題即可看該主題的 ETF 排行。
- **期間**：1週～10年、今年、上市以來，或自訂「N 個交易日／天／週／月／年」、自訂起訖日。
- **報酬模式**：不含息（價格）、含息再投入（總報酬）、含息不再投入。
- **指標**：期間報酬、年化報酬（≥1 年）、年化波動、最大回撤、期間配息、近 12 月配息率與次數、成交量、上市日、歷年報酬。
- **篩選**：主動／被動、投資地區、分類、主題、上市／上櫃、搜尋、成交量門檻、隱藏資料不足。
- **比較**：勾選最多 8 檔畫同一起點走勢圖，可對照大盤指數；點名稱看明細與配息紀錄；下載 CSV；網址保存全部設定可分享。

## 啟用

1. repo **Settings → Pages → Source** 選 **GitHub Actions**（workflow 也會嘗試自動開啟）。
2. **Actions → ETF 績效資料 → Run workflow**，第一次勾選「整段重抓」。約 5–10 分鐘後網站在 `https://<帳號>.github.io/<repo>/`。
3. 之後自動更新：台股週一～週五 15:10 與 18:40、週六 18:40；美股在美東收盤後（台灣隔日清晨 06:30 左右）。每週一次整段重抓，吸收資料來源事後修正。GitHub 排程常延遲數小時，實際更新時間會較晚。

本機執行：`python3 -m etf build --market all --full`（測試可加 `--limit 20`），然後直接用瀏覽器開 `docs/index.html`。

## 資料與定義

| 項目 | 來源／定義 |
|---|---|
| 台股 ETF 清單、上市日 | 證交所 ISIN 名冊（備援：證交所／櫃買中心每日收盤 OpenAPI） |
| 美股 ETF 清單 | 人工挑選並標註主題的約 250 檔（`etf/us.py`，可自行增減）；名稱與掛牌日取自 Yahoo Finance；資料自 2010 年起，以美元計 |
| 主題 | 台股依名稱關鍵字歸類（`etf/universe.py`），美股人工標註；主題報酬為主題內 ETF 等權平均 |
| 價格、除息 | Yahoo Finance 日線（市價，非基金淨值） |
| 不含息 | 期末收盤 ÷ 期初收盤 − 1 |
| 含息（再投入） | 每次除息日以當日收盤價把配息買回 |
| 含息（不再投入） | （期末收盤 ＋ 期間累計配息）÷ 期初收盤 − 1 |
| 期間起點 | 以日曆往前推，取該日或之前最近一個交易日；「交易日」直接數 K 線根數 |
| 年化波動 | 期間日報酬標準差 × √252 |
| 主動／被動 | 代號末碼 A 或名稱含「主動」為主動式 |
| 分割／反分割 | Yahoo 常漏掉台灣槓反 ETF 的反分割；相鄰兩日收盤比接近 2／3／4／5／8／10 倍（或其倒數）即視為分割並回溯調整，明細會標示 |
| 分類 | 代號末碼（A 主動股票、D 主動債券、T 平衡、B 債券、L 槓桿、R 反向、U 期貨）＋名稱關鍵字＋人工覆寫表（`etf/universe.py`） |
| 投資地區 | 台灣／海外／跨國（同時持有台灣與海外），同上；未經人工確認者顯示虛線框與「?」 |
| 資料較舊 | Yahoo 偶爾漏掉最新一根日 K，會先用即時報價欄位補；仍缺者在收盤欄標「至 MM/DD」 |

未計手續費、交易稅、二代健保補充保費與所得稅。槓桿／反向 ETF 每日重設，長期績效不等於指數倍數。僅供參考，非投資建議。
