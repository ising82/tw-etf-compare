# 📈 台灣 ETF 績效比較

全部台灣上市／上櫃 ETF（被動＋主動式）的績效比較網站，每個交易日自動更新，跑在 GitHub Actions + GitHub Pages 上，免伺服器、Python 只用標準函式庫。

- **期間**：1週～10年、今年、上市以來，或自訂「N 個交易日／天／週／月／年」、自訂起訖日。
- **報酬模式**：不含息（價格）、含息再投入（總報酬）、含息不再投入。
- **指標**：期間報酬、年化報酬（≥1 年）、年化波動、最大回撤、期間配息、近 12 月配息率與次數、20 日均量、上市日。
- **篩選**：主動／被動、投資地區（台灣／海外／跨國）、分類、上市／上櫃、搜尋、均量門檻、隱藏資料不足。
- **比較**：勾選最多 8 檔畫同一起點走勢圖，可對照加權指數／0050／0056／006208；點名稱看明細與配息紀錄；下載 CSV；網址保存全部設定可分享。

## 啟用

1. repo **Settings → Pages → Source** 選 **GitHub Actions**（workflow 也會嘗試自動開啟）。
2. **Actions → 台灣 ETF 績效資料 → Run workflow**，第一次勾選「整段重抓」。約 5–10 分鐘後網站在 `https://<帳號>.github.io/<repo>/`。
3. 之後週一～週六台灣時間 18:40 自動更新（週六整段重抓，吸收資料來源事後修正）。

本機執行：`python3 -m etf build --full`（測試可加 `--limit 20`），然後直接用瀏覽器開 `docs/index.html`。

## 資料與定義

| 項目 | 來源／定義 |
|---|---|
| ETF 清單、上市日 | 證交所 ISIN 名冊（備援：證交所／櫃買中心每日收盤 OpenAPI） |
| 價格、除息 | Yahoo Finance 日線（市價，非基金淨值） |
| 不含息 | 期末收盤 ÷ 期初收盤 − 1 |
| 含息（再投入） | 每次除息日以當日收盤價把配息買回 |
| 含息（不再投入） | （期末收盤 ＋ 期間累計配息）÷ 期初收盤 − 1 |
| 期間起點 | 以日曆往前推，取該日或之前最近一個交易日；「交易日」直接數 K 線根數 |
| 年化波動 | 期間日報酬標準差 × √252 |
| 主動／被動 | 代號末碼 A 或名稱含「主動」為主動式 |
| 分割／反分割 | Yahoo 常漏掉台灣槓反 ETF 的反分割；相鄰兩日收盤比接近 2／3／4／5／8／10 倍（或其倒數）即視為分割並回溯調整，明細會標示 |
| 分類 | 代號末碼（A 主動股票、D 主動債券、T 平衡、B 債券、L 槓桿、R 反向、U 期貨）＋名稱關鍵字＋人工覆寫表（`etf/universe.py`） |
| 投資地區 | 台灣／海外／跨國（同時持有台灣與海外），同上；名冊簡稱常看不出地區，歡迎回報錯誤 |

未計手續費、交易稅、二代健保補充保費與所得稅。槓桿／反向 ETF 每日重設，長期績效不等於指數倍數。僅供參考，非投資建議。
